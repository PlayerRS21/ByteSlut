What is ByteSlut?

ByteSlut is a local system monitor for Arch Linux. It runs silently in the background, collects data about how you use your computer, and shows it all in a web dashboard.

Everything runs on your machine only. No cloud. No telemetry. No accounts. Your data stays in a SQLite file on your drive.

Type byteslut in your terminal → dashboard opens in browser.

What it tracks: screen time, active time, per-app usage (hourly), browser history + YouTube titles, terminal commands + exit codes, CPU/RAM/temperature, network up/down, battery health, keystrokes + mouse, notifications, pacman packages
What it does NOT do: send data anywhere, record which keys you pressed, take screenshots, require root access, slow down your system (uses <1% CPU)

File Structure

Every file and what it does

First-time setup. Installs Python deps, adds you to 'input' group, creates systemd service, adds shell alias, patches hyprland.conf to pass env vars to systemd.
update.sh
Safe update script. Backs up config, stops daemon, copies new files, merges config (keeps your settings), runs DB migrations, restarts daemon.

Removes daemon, service, aliases, hooks. Keeps your database by default. Use --purge to delete everything.

All user settings. App name, CLI command, port, collection interval, privacy toggles, daily report time/thresholds, productivity app categories.
requirements.txt
Python dependencies: flask, psutil, dbus-python, PyGObject. Install with: pip install --break-system-packages -r requirements.txt

Daemon — Background Collector

The daemon runs as a systemd user service. It starts all collector threads and manages the database. You never run it directly — systemd handles it.

Core daemon files
daemon/main.py
Entry point. Starts all collector threads. Handles SIGTERM/SIGINT for clean shutdown. Health monitor loop checks if any thread died and logs it.
daemon/db.py
Database layer. Three key things:
1. get_connection() — SQLite with WAL mode
2. initialize_database() — creates all 14 tables
3. BatchWriter — collects records in RAM, flushes to SQLite every 30s
daemon/daily_report.py
Fires at 18:30 (configurable) to open the dashboard. Waits until system is relaxed (CPU <30%, temp not rising). Detects your terminal emulator (kitty, alacritty, foot…).
How BatchWriter works (important)

Writing to disk 500 times per second stresses old hardware. BatchWriter solves this:

Collector calls batch_writer.add("table", data)
↓ (stored in RAM list — instant, no disk)
Every 30 seconds: flush() is called
↓
All pending records written to SQLite in ONE transaction
↓
List cleared, ready for next 30s batch

Result: ~2 disk writes per minute instead of ~500. Old SSDs and HDDs both benefit.

Collectors — One File Per Feature

Each collector is completely self-contained in its own file. To update notification tracking, edit only notifications.py. Nothing else breaks.

collectors/session.py
Tracks screen time sessions. One session = lid open, not suspended.
DBus PrepareForSleep → instant suspend detect
Fallback Clock-jump: if heartbeat gap >300s = suspend
KEY BUG FIXED: SUSPEND_GAP must be >60s (heartbeat interval)
collectors/apps.py
Tracks active window every 2s. Polls /proc for background apps every 10s.
Hyprland hyprctl activewindow -j
Sway swaymsg -t get_tree
X11 xdotool getactivewindow
IMPORTANT: Injects env vars from /proc/$(pgrep Hyprland)/environ so systemd service can find Hyprland socket without HYPRLAND_INSTANCE_SIGNATURE being set.
collectors/cpu_ram.py
Collects CPU%, RAM%, swap%, disk delta, temperatures every 30s.
Temps from /sys/class/thermal/thermal_zone*/temp (millidegrees).
Writes temperature_daily (min/max/avg) on EVERY sample so dashboard always shows current values.
collectors/browser.py
Reads browser SQLite history files directly (no extensions needed).
Brave ~/.config/BraveSoftware/ + Flatpak path
Firefox ~/.mozilla/firefox/ + Flatpak path
Copies file to /tmp/ before reading (browser locks the live file).
Strips localhost/127.0.0.1 from results.
YouTube titles extracted from page title (removes " - YouTube" suffix).
collectors/notifications.py
Listens on DBus org.freedesktop.Notifications.
Requires: sudo pacman -S python-dbus python-gobject
Fallback: reads swaync's JSON cache file if DBus unavailable.
collectors/commands.py
Installs hooks into ~/.bashrc and ~/.zshrc.
Hook logs: TIMESTAMP|EXIT_CODE|PWD|DURATION|COMMAND to cmd_log.txt
Reads cmd_log.txt every 5s for new entries.
Imports existing bash/zsh history on first run.
collectors/network.py
Reads /proc/net/dev every 60s (cumulative counters → delta).
Per-app attribution: distributes total bytes across apps with active TCP connections (approximate).
collectors/battery.py
Reads /sys/class/power_supply/BAT0/ every 5 minutes.
Health% = (energy_full / energy_full_design) × 100
Tracks charge cycles if battery exposes cycle_count.
collectors/packages.py
Reads /var/log/pacman.log every 5 minutes.
Parses: [TIMESTAMP] [ALPM] installed/removed/upgraded PACKAGE (VERSION)
Tracks file position so only new lines are read.
collectors/input_tracking.py
Reads raw binary events from /dev/input/event* files.
Requires: sudo usermod -aG input $USER + logout/login.
Counts keystrokes, mouse clicks, scroll events, mouse distance.
WPM = (keystrokes in last 60s) / 5
collectors/productivity.py
Context-aware scoring (not just app name):
• YouTube + "Tutorial" in title → work
• YouTube + "Official Video" → entertainment
• github.com → always work
• bash/python3 scripts → neutral (never penalized)
Score = (work + comm×0.5 + other×0.6) / total × 100

How to Add a New Feature

Adding a new collector (e.g. track clipboard)

Step 1 — Create daemon/collectors/clipboard.py

class ClipboardCollector:
    def __init__(self, batch_writer):
        self.batch_writer = batch_writer
        self.running = False

    def run(self):
        self.running = True
        while self.running:
            # your logic here
            self.batch_writer.add("clipboard", {
                "content_hash": "abc123",
                "length": 42
            })
            time.sleep(10)

    def stop(self):
        self.running = False

Step 2 — Add a table in daemon/db.py inside initialize_database():

cursor.execute("""
    CREATE TABLE IF NOT EXISTS clipboard (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        timestamp INTEGER NOT NULL,
        date TEXT NOT NULL,
        content_hash TEXT,
        length INTEGER
    )
""")

Step 3 — Register in daemon/main.py:

from daemon.collectors.clipboard import ClipboardCollector
collector_configs.append(
    (ClipboardCollector, {"batch_writer": batch_writer})
)

Step 4 — Add a route in web/app.py + template in web/templates/ + nav link in base.html.

Step 5 — Run ./update.sh --restart-only

Adding a new dashboard page

Step 1 — Add route in web/app.py:

@app.route("/mypage")
def mypage():
    data = query("SELECT * FROM mytable")
    return render_template("mypage.html",
        config=config,
        data=data,
        format_duration=format_duration,
    )

Step 2 — Create web/templates/mypage.html:

{% extends "base.html" %}
{% block content %}
<div class="page-header">
  <h1>My Page</h1>
</div>
{% endblock %}

{% block scripts %}
<script>
  // page-specific JavaScript
</script>
{% endblock %}

Step 3 — Add link in web/templates/base.html sidebar:

<a href="/mypage" class="nav-link
  {{ 'active' if request.endpoint == 'mypage' }}">
  <span class="nav-icon">◈</span> My Page
</a>

Known Issues and How to Fix Them

SymptomRoot CauseFix
Apps all show 0s Systemd service doesn't inherit HYPRLAND_INSTANCE_SIGNATURE from your login session Add to hyprland.conf: exec-once = systemctl --user import-environment WAYLAND_DISPLAY HYPRLAND_INSTANCE_SIGNATURE XDG_CURRENT_DESKTOP DBUS_SESSION_BUS_ADDRESS
Screen time resets every ~2 minutes SUSPEND_GAP_SECONDS was 30, heartbeat runs every 60s — false suspend triggers every tick SUSPEND_GAP_SECONDS = 300 (5 minutes). Already fixed in v3+.
ByteSlut dashboard as top browser site Browser history collector was tracking localhost:6969 visits Localhost URLs now filtered in browser.py and all SQL queries. Fixed in v3+.
Same YouTube video appears twice (2) Gulaab and Gulaab treated as different titles (notification count prefix) SQL strips leading (N) prefix with GLOB before GROUP BY. Fixed in v3+.
Keystroke tracking not working User not in 'input' group — /dev/input/event* not readable sudo usermod -aG input $USER then FULL logout + login (not just terminal restart)
Notifications not tracked dbus-python not installed sudo pacman -S python-dbus python-gobject then restart daemon
Service doesn't autostart graphical-session.target not activated by Hyprland Service uses WantedBy=default.target. Also add import-environment to hyprland.conf.
System daemons in top apps (sd-pam), accounts-daemon etc. leak through background tracking is_system_process() filter in apps.py + SQL NOT IN/NOT LIKE filters in every query
Temperature shows different values on different pages Dashboard queried system_stats (individual readings), hardware page queried temperature_daily temperature_daily updated on every 30s sample. Dashboard queries temperature_daily as single source of truth.
